MockupWebsite

A mockup website project with separate frontend and backend components — designed to demonstrate a full‑stack web app setup.


🧩 Project Overview

MockupWebsite is a full‑stack web project that includes:

🖥️ Frontend – UI layer (HTML/CSS/JavaScript/SemanticUI)

⚙️ Backend – server‑side logic (Express, Nodejs, Mongoose)

To test it yourself:

    git clone https://github.com/Ckonst00/MockupWebsite.git
    cd MockupWebsite
  
    Frontend:
    cd web-frontend
    npm install
    npm start
  
    Backend:
    cd ../web-backend
    
    First you need to create .env file to the root of the backend and have these variables:
    MONGODB_URI=yourmongodblink
    PORT=8080
    SECRET=yoursecretkeyword
    
    npm install
    npm start
